SinalCerto 1.0.0: primeira versão de demonstração.

**O que o app faz:** mostra, em linguagem simples, como a internet deve estar em cada hora do dia na
região escolhida: Boa, Regular ou Instável. Ajuda a escolher a melhor hora para chamadas de vídeo,
envio de arquivos e outras atividades, com foco em acessibilidade (VoiceOver, texto grande, contraste,
48 dp).

**APK Android:** https://expo.dev/accounts/gabrieldotech/projects/sinalcerto-app/builds/2f70c8da-5365-4854-8e0c-24f30ff5b2b8
(passo a passo de instalação no README).

**Testes:**
- 243 testes automatizados passando; o GitHub Actions roda tipos, lint e testes em todo push na `main`.
- Cobertura em `src`: 95,39% das instruções, 87,84% dos ramos, 93,72% das funções e 96,37% das linhas.

**Limitações:**
- **Dados:** cobrem só 19 e 20 de agosto de 2026.
- **Região:** a previsão vale para a região, não para o celular, e o app não mede a conexão.
- **Jogos online:** ficou de fora, porque a API 0.2.0 não tem essa atividade.
- **Android:** o app ainda não foi testado num aparelho Android, nem com o TalkBack.
